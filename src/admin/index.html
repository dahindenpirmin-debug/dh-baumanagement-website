Anmelden

Die Referenzen liegen im GitHub-Repository der Website. Zum Speichern braucht dieser Bereich einen persönlichen Zugriffsschlüssel (Token), der nur in diesem Browser gespeichert wird.

So erstellen Sie den Token (einmalig, 2 Minuten)
  1. Auf github.com anmelden, oben rechts auf das Profilbild, dann Settings.
  2. Ganz unten links Developer settings, dann Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name z. B. «DH Website Admin», Ablauf nach Wunsch (z. B. 1 Jahr).
  4. Repository access: «Only select repositories» und nur das Website-Repository wählen.
  5. Permissions → Repository permissions → Contents: «Read and write». Sonst nichts.
  6. Generate token, den Schlüssel kopieren und hier einfügen.

Der Token gibt nur Zugriff auf die Dateien dieser Website. Auf einem fremden Gerät nach der Arbeit auf «Abmelden» klicken.
